`@studnicky/system` provides static host-system inspection: CPU topology, GPU detection (Metal, CUDA, ROCm), memory, and platform information, at `/node`, `/browser`, `/entities`, and `/interfaces`. `@studnicky/paginator` provides cursor and page-list state tracking for paginated data sources, at the same four entrypoints.
