`@studnicky/concurrency` provides `Throttle` (adaptive and fixed concurrency limiting with drain and abort control) at `/throttle/node`, `/throttle/browser`, `/throttle/entities`, and `/throttle/interfaces`. `@studnicky/fetch` provides HTTP-aware retry classification and backoff at `/retry`. `@studnicky/filters` scorer plugins import the browser-safe `@studnicky/matching/browser` entry. `@studnicky/eslint-config`'s browser entry exports the full rule plugin surface.
